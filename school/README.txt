SNACK+ School
=============

Open index.html in a browser. Works offline; data is saved in the browser (localStorage).

Files
- index.html   page shell
- app.css      styles (dark violet / orange glass theme)
- app.js       app logic, Export/Import/Reset, PNG export
- logo-data.js embedded logo for PNG export
- logo.png     logo
- icon.ico     favicon

GitHub Pages
Upload all files to the repository root, then enable Pages (Settings > Pages > Deploy from branch > main / root).
